# 单词小达人 · 微信小程序

## 功能概览

| 模块 | 说明 |
|------|------|
| 🏠 首页 | 每日学习进度总览，进入时自动播语音问候（每天换一句），一键进入各复习模块 |
| 📋 新单词 | 查看未学单词列表，点击开始闪卡学习 |
| ✏️ 导入单词 | 逐词录入 / 批量导入，自动联网获取释义+例句 |
| 🔄 复习 | 按艾宾浩斯间隔复习：3天拼写 / 5天选择 / 7天闪卡 |
| 🎳 永久记忆 | 已掌握词库，支持搜索（含词根词缀）、发音、查看例句、相关词跳转 |
| 👤 我的 | 个人主页：资料、学习目标与计划、打卡情况、学习效果评价与针对性建议 |
| 📝 单词详情 | 点击任意单词查看完整信息与复习进度 |
| 📁 文件导入 | 支持 TXT/PDF 文档解析、JPG/PNG 图片 OCR 识别单词 |

## 闪卡编辑 —— 任何模块都能改

不管单词出现在**新单词、复习（3/5/7天记忆）、永久记忆、单词详情**里的哪一个模块，
翻到闪卡背面都有一个 ✏️ 编辑按钮，可以直接修改**中文意思**、**用法说明**，并**增加/删除例句**，
点击保存立即写回本地数据库——不会影响单词当前所处的复习进度或永久记忆状态。

共享的编辑逻辑抽成了 `utils/wordFieldEditor.js` 一个模块，所有页面调用的是同一套（已测试）代码，
避免了"这个页面的编辑跟那个页面的编辑行为不一致"这种常见的维护陷阱。
（其中闪卡页与永久记忆页的编辑表单里还多一块**标注编辑面板**，见下文。）


## 闪卡增强功能（本次新增）

闪卡学习页（`pages/flashcard`）在原有"正反面翻转 + 发音 + 编辑"的基础上，新增了三块记忆增强能力：

### 1. 单词居中放大、逐字母可点
卡片正面单词**居中、放大**显示；单词被拆成**逐字母**，每个字母都可以单独点击。

### 2. 点击字母 → 按音节（音标结构）划分
- 点击任意字母，单词会**自动按音节切分**并高亮该字母所属的音节（虚线框 + 高亮底色）。
- 顶部「🧩 音节结构」按钮可手动开/关结构模式；点击字母会顺带打开结构模式并显示提示
  （例如点击 `remember` 的 `m`，提示「第 2 个音节：mem」）。
- 音节划分由 `utils/wordStructure.js` 的拼写/音标规则算法完成（数元音核 + 辅音段处理 + 连缀保护，
  如 th/sh/ch 等不拆开），用于帮助记忆读音结构。

### 3. 相关词母卡 + 原地展开
- 闪卡页顶部「🔗 相关词」按钮会弹出**底部母卡**，把当前单词的**关联词按标注分组**列出
  （前缀组 / 后缀组 / 词根组 / 合成组 / 关联组，各带中文含义与该组词数）。
- 点击母卡上的任意单词（或卡片底部的任一相关词胶囊），会**原地点开「它自己的相关词」面板**，
  可以继续往下钻、再点再展开，**不跳离当前卡片**，方便顺着关联网络一路看下去。
- 单词详情页（`pages/sentence`）新增「🃏 卡片模式」按钮，可把任意单词以卡片形式打开，
  从而也能使用上面的音节划分、标注与相关词能力。

> 说明：音节划分、词根词缀推断都是**启发式算法**，用于学习辅助，并非 100% 语言学精确；
> 个别标注可能存在漏标或多标，属正常现象。


## 单词标注与关联词

给每个单词自动打上**词根 / 前缀 / 后缀 / 合成 / 其他**标注，并用标注把单词彼此连起来。
标注可以**自动识别**，也可以**自己改**。

### 1. 卡片右上角显示标注
- 闪卡页正面、背面，以及永久记忆页的每张卡片，右上角都会显示该词的标注胶囊：
  - ➡️橙 `pre-` = 前缀，⬅️蓝 `-ation` = 后缀，🌱紫 `spect` = 词根，🧩绿 `含 flower` = 合成词，🏷️黄 = 其他（自定义）。
- **点标注 = 按这个标注去找同类词**：闪卡页弹出该标注下的单词母卡；永久记忆页则直接用该标注作为关键词搜索。
- 没有命中任何标注的基础词（如 `book`、`happy`）不显示标注，卡片保持干净。

### 2. 标注词之间互相链接
- 共享同一标注的单词自动互为**关联词**（同前缀、同后缀、同词根、同处一个合成词家族）。
- 关联关系由 `utils/wordAffix.js` 的 `buildIndex()` 一次扫描词库建立索引，
  单词 → 标注 → 其他单词形成一个可互相跳转的网络。

### 3. 卡片底部显示相关词
- 每张卡片底部有「🔗 相关词 · N」一排，直接列出关联词（最多先显示 4 个），
  **点一下就能跳到那个单词的卡片**。
- 每个相关词前面带一个**关系小图标**（🌱 相同词根 / 🧩 词缀相同 / 🤝 近义词 / ↔️ 反义词 …），
  一眼能看出它和本词是什么关系，不用点进去猜。
- 点「查看全部 ›」打开母卡，看到分组后的完整关联词表，每组都标着关系与词义，
  并标注每个词的学习状态（新单词 / 复习中 / 已掌握）——**自己加的关联还能在这一行直接 改 / 删**。
- 关联词取自**整个词库**（不只是永久记忆），所以能顺着一个已掌握的词发现还在复习中的同族词。

### 4. 搜索词根词缀或单词
- 永久记忆页的搜索框支持四种输入：
  - **单词 / 中文**：`inspect`、`检查` —— 照常匹配闪电卡列表；
  - **词缀**：`pre`、`pre-`、`-tion`、`ation` —— 命中标注后，顶部出现「🔖 词缀关联」区块，
    列出词库里所有带这个标注的单词（含学习状态，可直接点进卡片）；
  - **词根**：`spect`、`看`、`词根 spect`、`前缀`、`后缀` —— 同理列出该词根/该类标注下的全部单词；
  - **关系**：`近义词`、`反义词`、`相同词根`、`词缀相同`、`外形相近`、`同源词`、`关联词` ——
    列出用了这个关系的所有词（含自动识别出来的"相同词根 / 词缀相同"分组）。
- 自己手动加的标注（含中文标注，如"考试高频"）也能这样搜到。
- 已出现在「词缀关联」区块里的单词不会再在下面重复出现一次。

### 5. 手动添加 / 修改标注
闪卡页和永久记忆页的**卡片编辑表单**里都有一块「🏷️ 词根词缀标注」面板（两个页面共用同一个模板）：

- 打开编辑时，面板里**预填的是当前生效的标注**——没手动改过的词就是自动识别的结果，
  所以大多数情况下不用从零开始填，改一下就好。
- 每条标注可以改：**类型**（前缀/后缀/词根/合成/其他，点一下切换）、**文字**、**中文含义**、**删除**；
- 「➕ 加一个标注」自己加一条；「🔄 自动识别」把面板内容重置回算法识别的结果。
- 文字不用自己加横线：类型选"前缀"填 `pre`，卡片上就显示 `pre-`；选"后缀"填 `tion`，显示 `-tion`。
- **保存后立即生效**：卡片右上角标注、底部相关词、母卡分组都会跟着重算，
  新加的标注也马上能通过搜索找到——也就是说，你自己加的标注同样会把单词"连"起来。
- 手动保存过标注的词，之后就以你保存的为准（不会每次打开又被自动识别覆盖）；
  想回到自动识别，点一下「🔄 自动识别」再保存即可。
- 没手动动过标注的词，仍然跟随自动识别，词典以后扩充了它会自动受益。

### 6. 手动关联词（词↔词，补齐自动关联够不到的地方）
很多基础词（如 `book`、`happy`）推导不出任何词根词缀，自然也没有关联词。这类词、
或任何你想"强行"串起来的词，都可以**自己建立关联，并且随时改、随时删**：

- **入口就在相关词面板里**：打开相关词（卡片底部「查看全部 ›」），面板底部有一个
  「➕ 添加关联词」按钮——**不是只在"一个关联词都没有"时才出现**，任何时候都能加。
- **每条自己加的关联都能编辑**：面板里那条关联的标题右侧有 `✏️ 改` 和 `🗑`，
  可以**换关系、换成别的词、加/改备注、删掉**（删除会弹确认，只删关联不删单词）。
- **关联是双向的**：在 A 词里关联 B，打开 B 词的相关词面板也能看到 A（标题显示对面那个词）。
  但**只有"自己声明的那条"才能改**——在 B 这里看 A 是只读的，避免误改到 A 的数据。
- **没入库的词也能先记**：输入一个词库里还没有的单词名，会先以「待入库」的形式记下来，
  点它会提示先去导入；等这个词入库后关联自动变成可点击。

### 7. 每条关联词都标明「是什么关系」
这是"自己定义关联词"配套的重点：关联不只是连起来，还要说清楚**为什么有关**。

| 关系 | 图标 | 什么时候用 |
|------|------|-----------|
| 相同词根 | 🌱 | 共享同一个词根，意思往往相通 |
| 词缀相同 | 🧩 | 共享同一个前缀或后缀 |
| 外形相近 | 👀 | 拼写长得很像，注意别记混 |
| 同源词 | 🌳 | 由同一个词演变而来 |
| 近义词 | 🤝 | 意思相近，可以换着用 |
| 反义词 | ↔️ | 意思相反，成对记更牢 |
| 其他关联 | 🔗 | 自己定义的其它关系 |

- **加关联词时先选关系**：7 个关系按钮摆一排，选中会变色，下面一行给出这个关系的意思；
  还能写一句备注（如「加 un- 表示相反」），会显示在该关联的标题旁。
- **关系会自动猜**：输入单词时按 同词根 → 加/去词缀 → 拼写相近 的顺序猜一个并预选；
  猜的和用户最后选的不一样时，会提示一句「🤔 按拼写看更像 XX」，改不改由用户决定。
  同一个词改过之后会重新猜（关系是"这一对词"的属性）。
- **自动识别出来的关联也标关系**：词根组标「相同词根」、前缀/后缀组标「词缀相同」、
  合成词组标「合成词」。所以卡片上的每一个关联词，都能看出它和本词是什么关系。
- **关系优先于自动识别**：如果 `happy` 把 `unhappy` 标成反义词，那么打开 `unhappy` 时看到的是
  「反义词」，而不会被自动识别出来的「含 happy（合成词）」顶掉。
- **按关系搜索**：永久记忆页搜「近义词」「反义词」「相同词根」「关联词」等，
  会把用了这个关系的词全列出来（`词根 spect`、`前缀 pre` 这些老写法照旧）。

> 数据存在单词的 `links` 字段：`[{ text, id, rel, note }]`——`id` 命中词库时为真实可跳转关联，
> `null` 表示待入库；`rel` 是关系（老数据没有这个字段时按「其他关联」显示）；`note` 是备注。
> `wordAffix.buildIndex` 把每条手动链接建成一条带**声明者**的索引条目（`lk:<谁>#<谁>`），
> 这样 A→B 和 C→B 不会并成一组，也才能判断"这条关联是不是我声明的"。反向查看靠 `memberMap`。
> 保留关系的用户自定义与纯函数性质：`cleanStoredLinks` / `upsertLink` / `removeLink` /
> `findLinkByText` / `guessRel` 都在 `utils/wordAffix.js`，可直接 Node 验证。

> 实现集中在 `utils/wordAffix.js`（纯函数、不依赖 wx API，可单独跑 Node 验证）：
> 内置常用前缀/后缀/词根词典（带中文含义）→ 推断标注 → 建立标注索引 → 取关联词 / 按标注搜索。
> 词典在文件顶部的 `PREFIXES` / `SUFFIXES` / `ROOTS` 三个对象里，想补充直接加一行即可。
> 关系词典在 `REL_TYPES`（含中文名、图标、说明），编辑面板的选项由 `REL_OPTIONS` 生成。
>
> 编辑面板拆成了三块，各页不用重复写：
> `templates/tag-editor.wxml`（标注面板）+ `templates/link-editor.wxml`（关联词面板）+ 对应 `.wxss`（各页 `@import`），
> 事件处理分别在 `utils/wordFieldEditor.js` 的 `tagEditorMethods` 与 `utils/wordLinkEditor.js` 的 `methods`，
> 页面用 `Object.assign` 合并进 `Page()`。两个页面（闪卡、永久记忆）共用同一套，改一处两边都生效。
>
> 头像同理：`templates/avatar.wxml` + `avatar.wxss` 是首页与个人主页共用的头像组件，
> 取值逻辑在 `utils/storage.js` 的 `getAvatar`（详见「个人头像」一节）。


## 语音问候（进入首页自动播）

- 每次**启动小程序**、首页显示时自动播一句问候语；同一次启动里切 tab、回前台都不会重复播。
- 播哪一句**按日期轮换**：用本地日期距 1970-01-01 的天数对音频数量取余，
  所以同一天固定同一句，第二天自动换下一句。
- 播放时小达人会一晃一晃地说话，旁边冒出带音波的小喇叭气泡；播完就恢复安静悬浮。
- 首页左侧有「🔊 再听一次」按钮，想再听随时可以点。
- 问候语文件在 `sounds/1~5.greeting.mp3`，配置在 `utils/sound.js` 顶部的 `GREETINGS` 数组：
  **加一个音频文件 + 往数组里加一行**，轮换周期会自动按新数量算。


## 掌握 / 困难的语音反馈 + 花筒彩带

复习关（`pages/review`）卡片左下角「😓 困难」、右下角「🎉 掌握」；闪卡学习页的「✓ 我学会啦」按同一套逻辑给反馈。

### 点「掌握」（或"我学会啦"）
1. **花筒彩带**：屏幕下方左右两个花筒口（🎊）弹出来，18 片彩带/星星从两个口子向斜上方喷出，
   飞到最高点后旋转着自然落下。彩带层放在页面最外层（`position:fixed`），
   所以闪卡最后一张学完切到"学习完成"页时，彩带还在继续飞，不会被切掉。
2. **夸奖语音**：随机播一条「你真棒」类语音，**不会连着播同一条**：
   - `excellent.mp3`（项目原有的"棒极了"）
   - `praise-1.mp3`「你真棒！又记住一个单词啦！」
   - `praise-2.mp3`「太厉害啦，你真棒！」
3. 还有轻微震动 + 顶部提示（"真棒！进入下一环节～"）。

### 点「困难」
- 播一条**鼓励语音**（随机、不重复）：`encourage-1~3.mp3`
  （「没关系，慢慢来，再试一次就好啦！」/「别灰心，继续努力，你一定可以的！」/「加油，多练几遍就记住啦！」）
- 同时轻微震动并提示"已回到上一环节，继续加油～"，单词按原规则退回上一环节。

### 音频怎么加 / 怎么换
- 所有语音都在 `sounds/` 里，文件名写在 `utils/sound.js` 顶部的 `GREETINGS` / `PRAISE_FILES` / `ENCOURAGE_FILES` 三个数组里。
- **想加"掌声欢呼声"**：把 `applause.mp3` 放进 `sounds/`，在 `PRAISE_FILES` 里加一行 `'applause.mp3'` 就行，会自动进入随机轮换。
- `praise-*.mp3` / `encourage-*.mp3` 是用微软 Edge 神经网络语音（edge-tts）生成的，音质接近真人，
  单条约 20KB。想改文案重新生成的方法写在 `sounds/README.txt` 里。
- 连点也不会叠音：`playOnce` 播新语音前会先把上一段停掉。


## 个人主页（底部「我的」Tab）

底部 Tab 第 5 项「我的」。点右上角「✏️ 编辑」进入编辑态，一次把资料、学习目标、学习计划都改完。

### 1. 个人资料
昵称、真实姓名、年龄、学校、班级，以及**头像**。都只存在本机。
- 昵称用于界面称呼与语音问候；真实姓名填了就用真实姓名显示、并出现在评价文案里（"小明，你已经…"）；
- **年龄会影响建议内容**：≤8 岁、9~11 岁、≥12 岁给的是不同的学习量和学习方法；
- **头像**可以自己上传，或直接用当前等级的卡通形象（详见「个人头像」一节）。

### 2. 学习目标与学习计划（用户自己指定）
- **每天计划学几个新单词**（3/5/10/15/20，点一下选）——首页那排星星的完成度就按这个目标算，
  首页文案也变成「今日已学 x/目标」；
- **计划掌握多少个单词**（50/100/200/500/1000）+ 目标日期（可选）→ 显示进度条与完成百分比；
- **我的学习计划**自由填写，例如"每天晚饭后学 5 个单词，睡前再复习一遍"。

### 3. 学习打卡情况
- 今日状态（已打卡 ✅ / 未打卡 ⭕，未打卡时给一个「去学习 ›」按钮）；
- 连续打卡天数、累计打卡天数、最近一周打卡天数；
- 最近 7 天的小格子（⭐ = 当天有学习动作）。

打卡记录存在 `wm_checkins`，按天存 `{newCount, s1Count, s2Count, s3Count}`。
**只要有学习或复习动作就会自动记上**（挂在 `storage.incDaily` 里），不需要手动点"打卡"。
连续天数从今天往前数；今天还没学就从昨天开始数（当天还没结束，不算断签）。

### 4. 学习效果评价
3 个指标 + 1 句总评：

| 指标 | 怎么算 | 什么时候算好 |
|------|--------|--------------|
| 掌握率 | 永久记忆词数 / 接触过的总词数 | ≥60% 绿 |
| 最近一周打卡 | 最近 7 天有学习的天数 | ≥5 天绿 |
| 待复习 | `s1Due + s2Due + s3Due` | 0 个绿 |

总评会带上名字、等级、"接触过多少词 / 掌握了多少（掌握率）"、复习与打卡情况、目标进度。

### 5. 针对性学习建议
建议由 `utils/studyAdvice.js` 生成（纯函数、不依赖 wx API，可单独用 Node 验证），分两层挑选，
保证"因人而异"的建议不会被通用建议挤掉：

- **问题类（最多 3 条，按优先级）**
  1. 复习栏有到期的词 → 及时巩固复习单词栏目里的单词
  2. 某天一次学太多（≥15 个或 ≥2 倍日目标）→ 控制学习单词量，不要一次学太多
  3. 掌握率 <50% → 先了解单词意思或产生背景或描述的画面，帮助记忆单词
  4. 今天没打卡 / 连续 <3 天 → 坚持每天打卡背单词
  5. 最近一周学习天数 ≤4 → 合理安排学习时间，每天抽时间多看几遍单词
  6. 目标进度 → 距离目标还差多少个、按当前速度还要几天
  7. 词库太空（<20 个词）→ 先去导入单词
- **因人而异（最多 2 条）**
  - 按年龄：≤8 岁「一次 3~5 个、多听读音、和爸爸妈妈玩问答」／9~11 岁「读出声 + 看例句」／
    ≥12 岁「用词根词缀成组记（点卡片右上角标注看同族词）」
  - 等级高（恐龙/智人/超人档）→ 注意形近词辨析、把复习间隔拉长
  - 坚持得好（连续 ≥3 天或掌握率 ≥70%）→ 正向鼓励

想加或改建议：在 `utils/studyAdvice.js` 的 `PROBLEM_RULES` / `PERSONAL_RULES` 里加一条即可
（`when(ctx)` 决定要不要给、`build(ctx)` 拼文案、`priority` 决定先后，可写成函数做动态优先级）。

## 输入框与手机键盘（安卓 / iOS 都显示完整）

小程序的 `<input>` 在安卓和 iOS 上的默认表现不一样，之前踩过两个坑，现已统一修好。
**以后再加输入框，请照这三条写：**

### 1. 单个输入框必须显式给高度，上下内边距写 0
只写 `padding` 不写 `height` 时，安卓上 input 的默认高度很小，扣掉上下内边距和边框后内容框装不下字，
表现就是"输入框显示不全"（拼写关的输入框原来就是这样）。

```css
.example-input {
  box-sizing: border-box;   /* 必须 */
  height: 76rpx;            /* 必须：显式高度 */
  padding: 0 20rpx;         /* 上下内边距归零，左右保留 */
  border: 4rpx solid #E5E5E5;
  border-radius: 16rpx;
}
```

### 2. 放在 flex 行里的输入框必须加 min-width: 0
否则 iOS 上输入框会按自己的默认宽度撑出去、被容器裁掉，右侧显示不全
（"手动添加单词"的单词输入框 + 🔍 按钮那一行原来就是这样）。

```css
.example-input { flex: 1; min-width: 0; }
```

### 3. 键盘不要挡住输入框
- 所有 input / textarea 都加了 `cursor-spacing="24"`：键盘弹起时，光标与键盘之间至少留 24px。
- 闪卡页、永久记忆页额外加了**键盘态底垫**：输入框获得焦点时页面加 `.page-keyboard` 类（底部留 620rpx），
  这样卡片底部的输入框（尤其是标注面板）能被顶到键盘上方；失焦、保存、取消都会自动还原。
  这两个类的事件处理在 `utils/wordFieldEditor.js` 的 `onFieldFocus` / `onFieldBlur`，任何输入框都能直接挂。
- "手动添加单词"的单词框接了 `bindconfirm="fetchInfo"`：键盘上直接回车就查词，不用等 5 秒、也不必去点 🔍。

### 4. 底部弹层里的输入框要自己让位
弹层（相关词母卡 `position: fixed` 的那种）不会跟着键盘自动上移，键盘弹起会**整个盖住**里面的输入框。
所以相关词母卡里的"手动添加关联词"输入框这样处理：

- 页面上监听 `wx.onKeyboardHeightChange`（`onLoad` 注册、`onUnload` 注销），把键盘高度存进 `keyboardHeight`；
- 弹层根节点用 `style="padding-bottom: {{keyboardHeight}}px;"` 整体顶上去；
- 这个输入框自己加 `adjust-position="{{false}}"`（弹层已经让位了，再让页面滚一次会错位）+ `cursor-spacing="24"`。

涉及文件：`templates/tag-editor.wxss`（标注面板输入框）、`pages/importPage`、`pages/flashcard`、`pages/permanent`、
`pages/review`、`pages/sentence`、`pages/testSpell`。
> `pages/profile` 里的昵称输入框没动（该页未注册进 app.json，进不去）。

### 等级图鉴（没到那个等级也能先看到）

个人主页底部的「🏆 等级图鉴」把 9 张形象图**三列网格全摆出来**：
- **当前等级**：紫框高亮 + 「当前」角标
- **还没到**：半透明遮罩 + 🔒 锁
- 每张下面写名字、称号与积分区间

这样做的好处：小朋友一眼能看到"下一张长什么样"，有个具体的目标可盼，比只给一行文字有动力得多。
数据由 `pages/profile/profile.js` 的 `buildTierList()` 从 `MASCOT_TIERS` 生成（含 `tier` 字段供判断解锁）。

### 形象图是怎么来的 / 怎么换

9 张图是 AI 生成的**半身卡通形象**（大头、大眼睛、腮红、挥手打招呼，适合 6~14 岁），
之后做了三步处理：裁掉右下角水印 → 居中方形裁切 → 缩到 400×400 并存成 JPEG（quality 82）。
**9 张合计只有约 226 KB**（同样的图存 PNG 要 1.7 MB，小程序主包上限 2 MB，会直接撑爆）。

> **智人（`zhiren.jpg`）是按用户提供的参考图单独定制的**：保留了参考图的角色特征
> （羽毛头饰、珠串项链、米色流苏上衣、暖棕肤色、深棕乱发、腰间小皮袋），并沿用参考图的
> 半写实画风（柔和渐变、细腻阴影、自然人体比例）。所以它和其余 8 张的扁平卡通风格略有差异，
> 这是有意为之——用户希望智人这个"人类"等级更写实一些。
>
> 用参考图生成时有个坑：图生图（`image1`）的**风格传染很强**，只在 prompt 里写"忽略参考图风格"没用。
> 想让新图学风格就调高 `input_fidelity`；想只学特征、保自己的风格，则要用**文字主导 + 低 fidelity**。
>
> **超人（`chaoren.jpg`）也是按用户提供的参考图（《超人总动员》风格）定制的**：用高 `input_fidelity`
> 学参考图的 3D CG 画风与角色气质（金发、黑色眼罩、红黑配色超人服、橙腰带、披风、叉腰站姿），
> 但**胸口的标志换成了金色星星**——不照搬原作标志，避免版权问题。姿势与智人不同（智人挥手、
> 超人叉腰），刚好作为最高等级的"登场"感。

换图时照做即可：
1. 准备正方形构图、主体居中的插画（主体别太靠边，会被圆形裁切切掉）
2. 缩到 400×400，存成 JPG（quality 80~85 足够，别用 PNG）
3. 覆盖 `avatars/<名字>.jpg`，文件名不变就不用改任何代码

### ⚠️ 换了图但小程序里还是旧的？

**微信开发者工具和真机都会缓存图片**。换完 `avatars/` 里的图后如果在界面上没变化，按顺序试：

1. 开发者工具：点工具栏**「编译」**按钮旁边的下拉 → **「清缓存」→「全部清除」**，再重新编译；
   或者干脆关掉项目重新打开
2. 真机预览：把预览二维码**重新扫码**（旧预览是旧包）
3. 上传体验版/正式版：必须**重新上传版本**，并在小程序里退出重进（微信客户端也会缓存）
4. 手机端如果还不行：微信 → 我 → 设置 → 通用 → 存储空间 → 清理缓存

还有一个**最常见的误会**：等级形象图是**跟着积分自动切换**的，0~399 分显示鼠、400~799 显示猫……
**4000 分以上才轮到智人**（需要 800 个永久记忆单词）。所以如果你的积分还没到 4000，
换的智人图本来就不会出现在头像位上——这正是「等级图鉴」存在的意义：不用攒分也能看到全部 9 张。

## 单词批量导入

支持三种方式：
- ✏️ **逐词录入**：手动输入单词，失焦自动联网查词填充释义/例句
- 📋 **批量粘贴**：一段文字直接粘贴，支持换行、逗号、分号、空格任意组合分隔
- 📁 **文件导入**：TXT / **Word(.docx)** / PDF 文档解析、JPG / PNG 图片 OCR 识别

### 导入后的闪卡编辑
不管用哪种方式导入，"本次已添加"区域都会把新单词做成**闪卡**展示：
- 正面显示单词、音标、发音按钮，以及释义预览
- 点击卡片翻转到背面，可以直接编辑**中文意思**、**用法说明**，还能**增删例句**（跟逐词录入页面的表单字段完全一致）
- 点击"💾 保存"会立即写回本地数据库，联网查词没查到或查得不准确的单词可以马上手动补全/修正

### Word 文档解析原理
docx 文件本质是一个 ZIP 压缩包，内部包含 XML 格式的正文内容。小程序沙盒环境没有现成的解压库，
所以项目里自带了一套纯 JS 实现的 ZIP 解压 + DEFLATE 解码器（`utils/inflate.js`、`utils/zipUtils.js`），
经过与 Python `zlib`、`python-docx`、LibreOffice 的交叉测试验证，可以正确解析真实的 Word 文档。

## 永久记忆词库 —— 选择导出

点击右上角「选择导出」进入选择模式：
- 点击单词卡片进行**勾选**（此时不会触发翻卡，翻卡查看释义只在非选择模式下生效）
- 支持"全选/取消全选"
- 底部先选**导出内容模式**，再选格式导出：
  - **仅单词**：每个单词一行（含音标），不含中文释义/用法/例句，适合自测或导入其他工具
  - **详细卡片**：单词 + 音标 + 中文释义 + 用法 + 例句，一份完整的单词卡
- 底部操作条可选择导出为 **TXT / Word(.docx) / PDF**，或**批量删除**已勾选的单词
- 只导出**勾选**的单词；未勾选时点击导出会提示"请先勾选要导出的单词"

### 导出格式说明

| 格式 | 实现方式 | 中文支持 |
|------|---------|---------|
| TXT | 纯文本拼接 | ✅ 完整支持 |
| Word(.docx) | 手写 ZIP 打包（STORED不压缩）+ 标准 OOXML 文档结构 | ✅ 完整支持（阅读器用自己的字体渲染，不依赖导出时嵌入字体） |
| PDF | 先用小程序 canvas 把每页内容画成图片，再把图片嵌入手写的 PDF 结构 | ✅ 完整支持（因为是"画出来的图"，不依赖PDF自带字体） |

### 关于"导出到本地文件夹"

微信小程序运行在沙盒环境里，**没有权限直接写入手机的文件管理器/下载目录**。
项目采用官方支持的标准方案：生成好的文件先写入小程序私有临时目录，
再调用 `wx.shareFileMessage` 唤起**转发面板**，用户选择转发到「文件传输助手」（或任意聊天），
即可在对方/自己的聊天记录里长按保存到手机本地——这是小程序生态里最接近"导出到本地"的官方做法。

> 若当前微信版本不支持 `wx.shareFileMessage`、或用户取消了转发，会自动降级：
> 对 `.docx` / `.pdf` 调用系统 `wx.openDocument` 直接预览（带右上角菜单可再转发/保存）；
> 对 `.txt` 或预览失败时，弹出提示告知文件已生成在本地、可在微信文件管理中查找转发。



## ⚠️ 微信小程序后台必须配置合法域名

在「微信公众平台 → 开发管理 → 开发设置 → 服务器域名」中添加：

| 用途 | 域名 |
|------|------|
| 翻译（谷歌，可选，需VPN） | `https://translate.googleapis.com` |
| 发音 + 中文释义（有道，免费）| `https://dict.youdao.com` |
| 单词详细信息/音标/例句 | `https://api.dictionaryapi.dev` |
| 翻译兜底（免费） | `https://api.mymemory.translated.net` |
| 翻译（百度，可选，更稳定） | `https://fanyi-api.baidu.com` |
| 文件/图片OCR识别 | `https://api.ocr.space` |

> 📌 **关于查词失败**：`dictionaryapi.dev`、`mymemory.translated.net`、`translate.googleapis.com`
> 都是境外服务，国内网络环境下经常连不上或很慢，这是正常现象、不是代码bug。
> 如果逐词录入页面显示"未找到释义"，点旁边的"查看详情"能看到具体是哪个来源失败了——
> 显示"境外"或"需VPN"字样属于正常现象，直接手动填写即可；如果连"国内"来源都失败，才需要检查网络或域名白名单配置。

### 查词优先级（从上到下依次尝试，前一个失败才会用下一个）

```
① 谷歌翻译（免费，无需注册，但国内必须开VPN/代理才能连通，没开会自动快速降级）
② 百度翻译（需要自己申请appid+密钥，见下方步骤；未配置则自动跳过）
③ 有道建议接口（免费、国内可直连，但非官方文档保证的接口）
④ MyMemory翻译（境外，最后兜底）
```

这样设计的好处：**开了VPN的用户能用到质量最好的谷歌翻译**；**没开VPN的国内用户**，
谷歌请求会很快失败（超时设置得比较短，不会拖慢体验），自动降级到国内可直连的百度/有道，
两头都照顾到，不需要用户自己判断该用哪个。

### 可选：接入百度翻译获得更稳定的查词效果

有道的免费查词接口不是官方文档保证的正式API（本质是"借用"有道App内部使用的接口），
理论上存在哪天被限流或改版的风险。如果想要更稳定、官方文档保证的查词效果，可以接入
**百度翻译开放平台**：

1. 前往 [https://fanyi-api.baidu.com](https://fanyi-api.baidu.com) 免费注册开发者账号
2. 申请"通用文本翻译"服务，获得 **APPID** 和**密钥**（个人认证后每月100万字符免费额度）
3. 打开 `utils/api.js`，找到这两行：
   ```js
   const BAIDU_APP_ID = '';      // TODO: 替换成你申请到的百度翻译 APPID
   const BAIDU_SECRET_KEY = '';  // TODO: 替换成你申请到的百度翻译 密钥
   ```
   填入你申请到的 APPID 和密钥
4. 记得在小程序后台加上 `https://fanyi-api.baidu.com` 域名白名单

不配置百度翻译完全不影响使用，会自动跳过、走免费方案（谷歌/有道/MyMemory）。

> 百度翻译签名算法（MD5）已用官方文档给出的示例数据交叉验证过，谷歌翻译的接口格式
> 也用多篇独立技术文档交叉核实过，都不是凭记忆猜测写的。

> 导出功能（TXT/Word/PDF）全部在本地生成，不需要额外的域名白名单。

> 开发阶段可在「微信开发者工具 → 详情 → 本地设置 → 不校验合法域名」临时关闭校验。

## 📁 文件导入说明

- **TXT 文档**：直接读取文本内容，用正则提取英文单词，自动过滤常见虚词（a/the/is 等）。
- **PDF 文档 / JPG / PNG 图片**：调用 OCR.space 免费识别接口提取文字，再做同样的单词提取。
- 识别完成后会展示词条卡片供勾选，确认后才会调用查词接口批量导入，避免误导入无关内容。
- 默认使用 OCR.space 官方公开测试 Key（`helloworld`），有请求频率限制；正式使用建议前往
  [ocr.space/ocrapi](https://ocr.space/ocrapi) 免费注册专属 Key，替换 `utils/api.js` 中的 `OCR_API_KEY` 常量。
- 选择文档时会调起微信自带的「聊天记录选择器」（`wx.chooseMessageFile` 官方限制），
  需要先把文件转发到「文件传输助手」或任意聊天中才能选中。
